# Java Day 15 - Simple Calculator

## Description

This program creates a simple calculator using the `switch` statement in Java.

The user enters two numbers and an operator. The program performs addition, subtraction, multiplication, or division based on the selected operator.

## Example

```text
Enter first number: 20
Enter operator (+, -, *, /): *
Enter second number: 5
Result = 100.0
```

## Concepts Used

* Scanner
* User Input
* double
* char
* switch statement
* case
* break
* default
* Arithmetic Operators
* if-else

## How It Works

1. The program takes the first number from the user.
2. It takes an operator such as `+`, `-`, `*`, or `/`.
3. It takes the second number.
4. The `switch` statement checks the operator.
5. The matching case performs the calculation.
6. The result is displayed on the screen.
7. Division by zero is handled using `if-else`.

## Operators Supported

| Operator | Operation      |
| -------- | -------------- |
| `+`      | Addition       |
| `-`      | Subtraction    |
| `*`      | Multiplication |
| `/`      | Division       |

## File Name

`Main.java`

## Goal

The goal of this program is to understand how the `switch` statement can be used to perform different operations based on user input.
